# FileNest για Windows

Εδώ διατίθενται μόνο οι εγκαταστάτες MSI, οι δημόσιες υπογραφές ενημέρωσης και τα manifests του FileNest. Ο πηγαίος κώδικας παραμένει ιδιωτικός. Τα αυτόματα Source code ZIP/TAR του GitHub περιέχουν μόνο αυτό το αποθετήριο διανομής.

[Δοκιμαστική έκδοση 0.11.2](https://github.com/alobar-dim/FileNest-Releases/releases/tag/v0.11.2) · [Σταθερός δίαυλος ενημερώσεων](https://github.com/alobar-dim/FileNest-Releases/releases/latest) · [Οδηγός χρήσης](https://filenest-guide.alowind.chatgpt.site)

Η **0.11.2** διατίθεται για χειροκίνητη εγκατάσταση, μετά από επιτυχημένο έλεγχο Windows CI:

- [Ελληνικός εγκαταστάτης MSI](https://github.com/alobar-dim/FileNest-Releases/releases/download/v0.11.2/FileNest_0.11.2_x64_el-GR.msi)
- [English MSI installer](https://github.com/alobar-dim/FileNest-Releases/releases/download/v0.11.2/FileNest_0.11.2_x64_en-US.msi)

Πρόκειται για δοκιμαστική έκδοση χωρίς πιστοποιητικό Windows Authenticode και χωρίς υπογραφή αυτόματης ενημέρωσης. Τα Windows μπορεί να εμφανίσουν προειδοποίηση άγνωστου εκδότη. Οι αναφορές επαλήθευσης και οι τιμές SHA-256 βρίσκονται στη σελίδα της έκδοσης. Ο σταθερός δίαυλος αυτόματων ενημερώσεων παραμένει στην **0.10.4**.

Από την εφαρμογή: **Ενημερώσεις → Έλεγχος ενημερώσεων → Ενημέρωση και επανεκκίνηση**. Ο καθημερινός έλεγχος και η λήψη γίνονται στο παρασκήνιο. Η εγκατάσταση περιμένει να ολοκληρωθούν οι εργασίες αρχείων και διατηρεί ρυθμίσεις και ιστορικό. Δεν απαιτείται λογαριασμός GitHub.

Τα πακέτα του σταθερού διαύλου διαθέτουν κρυπτογραφική υπογραφή ενημέρωσης FileNest. Η χειροκίνητη δοκιμαστική 0.11.2 διατίθεται χωριστά. Εκκρεμεί το πιστοποιητικό Windows Authenticode. Τα Windows μπορεί να ζητήσουν έγκριση διαχειριστή για την εγκατάσταση.
